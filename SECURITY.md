# Security policy

LibreEcho-Platform is part of LibreEcho. Security issues in this repository are handled
under the [LibreEcho security policy](https://github.com/aslater3/LibreEcho/blob/main/SECURITY.md),
which sets out supported versions, scope, response targets and disclosure.

## Report privately

Do not open a public issue or pull request with vulnerability details. Use
GitHub's private vulnerability reporting, either here or on the main
repository:

<https://github.com/aslater3/LibreEcho/security/advisories/new>

Never include passwords, tokens, keys, Wi-Fi credentials, serials, MAC
addresses, private IPs or owner-local firmware in a report.

## Scope for this repository

Initramfs and root filesystem contents, service supervision, OTA packaging
and verification, feature payloads, network services (including ADB, SSH,
mDNS and the recovery access point), and build or release tooling.

## Advisories

Confirmed vulnerabilities are published as GitHub Security Advisories on the
main LibreEcho repository and listed in the
[advisory archive](https://github.com/aslater3/LibreEcho/blob/main/SECURITY-ADVISORIES.md).
